### http用法
```golang
func (h *Handler) PlaceOrder(w http.ResponseWriter, r *http.Request) {

	var order model.Order

	json.NewDecoder(r.Body).Decode(&order)//从 HTTP 请求的 Body 中读取 JSON 数据，并将其解析到 order 变量中。(放入用户输入的订单数据)

	h.Engine.PlaceOrder(&order)//存订单信息

	w.Write([]byte("ok"))//向客户端返回一个http响应
}
```
- `w http.ResponseWriter`：用于**发送 HTTP 响应**的接口（写回数据、设置状态码等）。
- `r *http.Request`：代表客户端发送的 **HTTP 请求**对象（包含请求方法、URL、Body 等）。

### main函数里http
- `http.HandleFunc("/order", handler.PlaceOrder)`：注册路由。当有请求访问 `/order` 路径时，调用 `handler.PlaceOrder` 函数来处理。
- `http.ListenAndServe(":8080", nil)`：启动 HTTP 服务，监听本机 `8080` 端口。`nil` 表示使用默认的路由器（即上面注册的路由）。

### MYSQL
`go get github.com/go-sql-driver/mysql`要安装go的数据库驱动

**创建一个和数据库连接的`变量`，用这个变量操控数据库**
1. **`dsn := "root:password@tcp(127.0.0.1:3306)/exchange"`**  
   定义数据库连接**字符串**（用户名:密码@协议(地址:端口)/数据库名）

2. **`db, err := sql.Open("mysql", dsn)`**  
   用 MySQL 驱动和 DSN 打开一个数据库连接（返回连接对象和错误）

3. **`if err != nil { log.Fatal(err) }`**  
   如果打开连接时报错，则打印错误并终止程序

4. **`DB = db`**  
   将连接对象赋值给全局变量 `DB`（供其他地方使用）

实际生产中，订单完成和订单取消都仅在数据库中更新订单状态，不直接删除订单

`.Scan(&available, &frozen)`将sql查询结果放到available和frozen变量中

**事务：**
用 `tx := db.Begin()` 开启事务，后续 **所有 DB 操作必须用 `tx`**，最后 `tx.Commit()` 或 `tx.Rollback()`。

`change.String()`数据库驱动不认识 decimal.Decimal 类型，不转字符串存不进去
