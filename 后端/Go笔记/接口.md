## 接口
任何类型都可以实现接口，只要该类型实现了接口中的所有方法。
```golang
//如何声明接口
type shape interface {
    area() int // 函数方法(参数)(返回类型)
}

type rect struct {
	width int
	height int
}

func (r rect) area() int {
	return r.width * r.height
}

func main() {
	r := rect{width: 10, height: 20}
	fmt.Println(r.area())
}
```
## 嵌入字段
```golang
type A struct {
    a1,a2 int
    B
}

type B struct {
    b1,b2 int
}

func (b B) method() int {
    return b.b1 + b.b2
}

func main() {
    b := B{10,20}
    a := A{1,2,b}

    fmt.Println(a.b1)//可以从a拿到属性
    fmt.Println(a.method())//可以从a调用B的方法
}
```
