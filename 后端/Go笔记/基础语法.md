# 基础语法
## 变量声明
1.变量声明格式：`var i = 100`

```golang
var (
    i int
    s string
)
```

2.简写：`i := 100`
## 常量声明
`const s = "hello world"`

`const n = 10000`
## 类型的用法
### 声明结构体类型
```golang
import(
    "fmt"
)

type example struct{
    age int
    name string
}

var person example

fmt.Println(person)
```
### 声明接口类型
```golang
type example interface{
    color() string
    genre() string
}
```
## 函数声明
```golang
func hello(input string) string {
    return input
}
```
函数名首字母大写”公开“，首字母小写“私有”（仅本包可访问）

匿名函数的使用
```golang
n := func() {
    // 函数逻辑
}

n()// 调用匿名函数
```

### 多个返回值
```golang
func name() (int,int){
    return 3,7
}
```
## 条件语句
```golang
if age >= 18 {
    fmt.Println("成年人")
} else {
    fmt.Println("未成年人")
}


//先执行语句+条件
if 语句; 条件{
    执行逻辑
}
```
### switch
```golang
switch i {
    case 1:
        fmt.Println("i is 1")
    case 2:
        fmt.Println("i is 2")
    default:
        fmt.Println("i is not 1 or 2") 
}
```
### for
```golang
i := 1
for i <= 3 {
    fmt.Println(i)
    i = i + 1
}//像while

for j := 1; j <= 3; j++ {
    fmt.Println(j)
}//像普通的for

for i := range 3 {
    fmt.Println(i)
}//range


```
