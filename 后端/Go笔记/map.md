# map
## 旧版
### hmap
结构体，存有：元素数，桶数，桶数组（指针），旧桶(指针，用于扩容)，哈希指针

每个桶可以存储多个键值对，桶数由log2（桶数）表示
### bmap
单独的一个桶，最多存储8个键值对
结构体，存有三个数组：键数组，值数组，哈希高8位
### 存入过程
1.根据键计算哈希值

2.用哈希定位存到哪个桶里，拿到bmap

3.在bmap内找哈希高8位数组中等于0的位置

4.写入值

5.更新hmap元素数量，键值对数量...
### 查找过程
1.计算键的哈希值，定位到桶bmap，遍历查找
## map并发不安全
不能进行并发读写

解决方法：加锁
```golang
var mu sync.RWMutex
m := make(map[int]int)

go func() {
    for i := 0; i < 10000; i++ {
        mu.Lock()
        m[i] = i
        mu.Unlock()
    }
}()

for i := 0; i < 10000; i++ {
    mu.RLock()
    _ = m[i]
    mu.RUnlock()
}
```
**map的遍历顺序不是写入顺序**
