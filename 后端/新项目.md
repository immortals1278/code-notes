# 依赖
创建模块，依赖下在模块里
```
//进入项目根目录
cd "d:\project\Atlas Trading Infrastructure"

// 初始化 Go modules（请替换为你自己的模块名）
go mod init atlas-trading-infrastructure

// 下载 zap 依赖
go get go.uber.org/zap

// 自动扫描你代码里所有的 import，删除多余，添加缺失的依赖
go mod tidy
```

**Go 语言中只有大写开头的变量才能被外部包访问。**

**导入路径：模块名/项目中的目录/目录**
