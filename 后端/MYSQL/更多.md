## 索引
`CREATE INDEX idx_user_time ON order(user_id, create_time);`
在order表上创建索引：把 user_id 和 create_time 两列的数据复制一份，按 user_id 先排序，相同 user_id 的再按 create_time 排序，建B+树，加指针。

这样让查询加快，用空间换时间

```sql
CREATE TABLE `user` (
    id INT PRIMARY KEY,
    age INT,
    KEY idx_age (age)  -- 这里用 KEY，是建表时一起创建索引
    -- ↑ KEY 就是 INDEX 的别名
);

CREATE INDEX idx_age ON user(age); -- 上面等价于这行
```

## 事物
由一个或多个sql语句构成，要么全部执行成功，要么全部执行失败。（原子性）

用`begin;`开启一个事务，用`commit;`提交事务，`用rollback;`回滚事务。
### 四种隔离级别
READ UNCOMMITTED（读未提交）

一个事务可以读取到另一个未提交事务的数据。

⚠️ 可能出现：脏读 **不推荐使用**

READ COMMITTED（读已提交）

只能读取到已提交事务的数据。

⚠️ 可能出现：不可重复读：同一事务内读取到不同值

REPEATABLE READ（可重复读）

在同一事务中多次读取同一数据结果一致。

⚠️ 可能出现：幻读）

SERIALIZABLE（串行化）

通过锁按顺序执行事务，但不支持高并发
## 间隙锁
RR隔离级别下，查询不存在的数据时（未提交），不能插入 这个“不存在的数据”

eg：查询age = 25时，但age = 25的记录不存在，别的事务不能插入age = 25的数据
