# 环境搭建
## 安装
`https://github.com/tporadowski/redis/releases`双击下载`Redis-x64-5.0.14.1.msi` 或类似的文件，启动安装向导。

勾选`Add Redis to the system PATH`，在任意命令行窗口直接使用 Redis 命令

## navicat
数据库可视化客户端管理工具

下载：
`https://www.navicat.com.cn/download/navicat-premium-lite`
## 创建redis服务器
开机自启动（用MSI安装包下载）
## 将redis服务器与navicat连接
打开navicat左上角点连接，选redis
## 选择数据库
双击左侧的`你的连接名`，双击`几号数据库`
## 写代码
打开navicat点`ctrl + Q`打开查询编辑器

**这些指令在实际生产中写在GO等后端语言代码里**
## 运行
可以选择代码只运行选择的部分

结果返回1表示成功
