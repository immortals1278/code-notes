## Channel

2.分为有缓冲区，没缓冲区

```golang
ch := make(chan int)//无缓冲区
```

## Select
```golang
ch1 := make(chan string)
ch2 := make(chan string)//定义两个协程通信的channel

go func(){
    time.sleep(2*time.second)//模拟真实业务执行耗时
    ch1 <- "message1"
}()

go func(){
    time.sleep.(1*time.second)
    ch2 <- "message2"
}()

for{
    select{
    case message1 := <-ch1:
        fmt.println("receive message",message1)
    case message2 := <-ch2:
        fmt.println("receive message",message2)
    }//监听谁有值谁执行，谁先有信号谁执行
}//主协程定义一个死循环

```
## 互斥锁
`Mutex`被加锁的对象同一时刻只能被一个协程进行操作

```golang
import(
    "sync"
)

type container struct {
    mu sync.Mutex//定义一个互斥锁
    count map[string]int
}

func (c *container) inc (name string, value int) {
    c.mu.lock()//通过c里的lock给c加锁
    defer c.mu.unlock()//defer：return之后执行这一行
    c.count[name]++
}


var c = container{
    count : map[string]int{"a":0,"b":0},
}

var wg sync.waitGroup//定义一个waitGroup

var update = func(name string, n int){
    for range n{
        c.inc(name)
    }
}

wg.Go(func(){//wg启动一个goroutine（协程）执行传入的函数
    update("a",100)
})

wg.Go(func(){
    update("b",200)
})

wg.Wait()//等待所有协程执行完毕才会往后执行

fmt.Println(c.count["a"],c.count["b"])
```
### waitGroup
`wg.Go()`相当于把 `wg.Add(1)`（加一个协程）和 `wg.Done()`综合在一起
## Context
网络请求的处理的上下文，它可以携带请求的数据，可以实现超时退出，主动退出等操作（相当于请求失效）
```golang
ctx,cnacel := context.WithCancel(context.Background())
//返回一个上下文对象，里面包含了一个channel
// 返回一个取消函数（执行ctx.Done()）

go func(){
    select{
        case <- ctx.Done():
            fmt.Println("context canceled")
        case <-time.After(2*time.Second):
        //after也是个channel
            fmt.Println("timeout")  
            //如果两秒后cancel没被执行，ctx没有done，就会出现执行这里
    }
}()

cancel()
//会输出"context canceled"
```
```golang
ctx, _ := context.WithTimeout(context.Background(),3*time.Second)//下划线接受一个返回值，忽略它
//表示3秒后超超时然后done()

go func(){
    for range 20 {
        select{
            case <- ctx.Done():
                fmt.Println("context canceled")
            case <-time.After(2*time.Second):
                fmt.Println("timeout")  
        }
    }//第二秒输出timeout，第三秒输出context canceled，然后一直输出context canceled20次（因为此时的ctx已经done了）
}()

time.sleep(6*time.Second)

```
## 装饰器
通过包装函数来增加他的功能但不修改原函数本身

一个函数：入参是一个函数，返回值也是一个函数
```golang
func greet(name string) {
	fmt.Printf("Hello, %s!\n", name)
}

// 装饰器：添加日志
func logDecorator(fn func(string)) func(string) {
	return func(name string) {
		fmt.Println("Before calling function")
		fn(name)
		fmt.Println("After calling function")
	}
}

func main() {
	// 使用装饰器
	decoratedGreet := logDecorator(greet)

	// 调用装饰后的函数
	decoratedGreet("World")
}
```
## 闭包
一个函数是另一个函数的返回，且内部函数引用了外部函数的变量

多个闭包可以共享同一个外部变量
```golang
// outer 函数返回一个闭包函数
func outer() func() int {
    //表示 outer() 返回的函数在被调用时会返回一个 int 类型的值。
	x := 0 // 外部变量
	return func() int {
		x++ // 闭包捕获并修改外部变量
		return x
	}
}

// TestClosure 演示闭包的特性
func main() {
	f := outer()   // outer返回后，x仍然存在
	fmt.Println(f()) // 输出: 1
	fmt.Println(f()) // 输出: 2
	fmt.Println(f()) // 输出: 3
}
```
