# 数据结构
## 数组
```golang
//声明
var a [5]int
b := [5]int{1,2,3,4,5}
c := [...]int{1,2,3,4,5}//编译器推断数组长度

a[4] = 100//赋值
```
## 切片
数组的长度是固定的，切片是动态的
```golang
//声明
var s []string//len是0，s是nil
var a = make([]string,len,cap)//a不是nil，len不是0，容量最大为cap，容量如果没指定就是len
t := []string{"a","b","c"}

fmt.Println(s == nil)
fmt.Println(len(s) == 0)

//append
t.append("d")

```
## map
```golang
//声明
map1 := make(map[string]int)
//赋值
map1["a"] = 100
//取值
v := map1["a"]
//删除与清空
delete(map1,"a")
clear(map1)
```

### 结构体方法
```golang
type rect struct {
	width int
	height int
}

func (r rect) area() int {
	return r.width * r.height
}

func (r *rect) perim() int {
	r.width = 100//指针类型的可以修改原值
	return 2*r.width + 2*r.height
}
```
## 指针
`&i`表示取i的存储地址
```golang
func zeroptr(iptr *int) {//iptr是int指针，*int是指针类型
	*iptr = 0//将指针iptr指向的值设置为0
}

func Value(val int){
    val = 2
}

i := 100
zeroptr(&i)
fmt.Println(i)//输出0

//指针传递和值传递的区别
k := 100
Value(k)
fmt.Println(k)//输出100,对指针操作才会改变k的值
```
