## 变量声明
1.变量声明格式：`var i = 100`

2.简写：`i := 100`
## 常量声明
`const s = "hello world"`

`const n = 10000`
## 类型的用法
### 声明结构体类型
```
type example struct{
    age int
    name string
}

var person example

fmt.Println(person)
```
### 声明接口类型
```
type example interface{
    color() string
    genre() string
}
```
## 函数声明
```
func hello(input string) string {
    return input
}
```
### 多个返回值
```
func name() (int,int){
    return 3,7
}
```
